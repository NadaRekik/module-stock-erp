# Module Stock de l'ERP : diagrammes BPMN

Modélisation BPMN 2.0 des processus du module Stock d'un ERP (projet à quatre).

## Équipe et processus

**Amine**
- Réception : `reception.bpmn`
- Gestion des articles : `gestion-articles.bpmn`
- Mise en stock : `mise-en-stock.bpmn`

**Nada**
- Sortie : `sortie.bpmn`
- Réservation : `reservation-stock.bpmn`
- Retours : `retours.bpmn`

**Salma**
- Inventaire : `inventaire.bpmn`
- Réapprovisionnement : `reapprovisionnement.bpmn`
- Transfert interne : `transfert-interne.bpmn`

**Yasmine**
- Ajustement / casse / rebut : `ajustement_casse_rebut.bpmn`
- Lots / péremption : `lots-peremption.bpmn`
- Configuration : `configuration.bpmn`

**Vue d'ensemble** : `vue-ensemble.bpmn`
